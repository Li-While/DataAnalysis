# 数据分析与挖掘实训：心血管患病预测

## 技术栈

- Python 3
- pandas：数据读取、描述性统计、预处理、哑变量处理
- numpy：数值计算（新增 BMI 特征）
- matplotlib + seaborn：直方图、饼图、条形图、核密度曲线、箱线图、散点图、热力图
- sklearn：逻辑回归、随机森林、梯度提升树、KNN、SVM，MinMaxScaler 离差标准化，GridSearchCV 网格搜索

## 数据来源
数据来自 Kaggle 公开的 Cardiovascular Disease 数据集。共 70000 条记录，其中心血管疾病患者 34979 人，未患病 35021 人，三类特征、12 个输入字段 + 1 个目标字段。

## 字段说明

| 来源类别 | 列名 | 含义 |
| --- | --- | --- |
| 患者编号 | id | — |
| 生理指标 | age | 年龄（单位天） |
| 生理指标 | height | 身高（cm） |
| 生理指标 | weight | 体重（kg） |
| 生理指标 | gender | 1=女性，2=男性 |
| 医疗指标 | ap_hi | 收缩压 |
| 医疗指标 | ap_lo | 舒张压 |
| 医疗指标 | cholesterol | 正常为1，超标为2，严重超标为3 |
| 医疗指标 | gluc | 血糖浓度，正常为1，超标为2，严重超标为3 |
| 主观信息 | smoke | 是否经常吸烟，是为1，否为0 |
| 主观信息 | alco | 是否经常饮酒，是为1，否为0 |
| 主观信息 | active | 是否经常运动，是为1，否为0 |
| 患病情况 | cardio | 目标字段，患病为1，未患病为0 |

## Notebook 分析流程

### 1. 数据读取与展示

在 Jupyter Notebook 中用 `pd.read_csv` 读取，查看字段类型、数据形状（70000 行 × 13 列）、describe 描述性统计。

### 2. 可视化探索性分析

使用多种图表从不同角度观察数据：

- **离散型特征分布直方图**：age、gender、cholesterol、gluc
- **胆固醇水平饼图**：正常人群占 74.8%
- **血糖浓度条形图**：超出和大量超出正常水平约占七分之一
- **年龄直方图**：区间 30–65 岁，50–60 岁人数最多
- **身高/体重/血压核密度曲线**
- **年龄+性别分组条形图**：随年龄增加患病比例上升，性别影响不大
- **身高-体重散点图、分组箱线图**
- **相关性系数热力图**：患病与收缩压、年龄、BMI、体重相关性较强

### 3. 数据预处理

- 年龄字段：`age = round(age / 365)` 天转年
- 剔除身高、体重异常值：身高 < 140cm 且体重 < 40kg，剔除 198 条
- 剔除血压异常值：收缩压限定 `[60, 250]`，舒张压限定 `[30, 180]`，剔除 1215 条
- 去重：`drop_duplicates()`
- 哑变量处理：gender、cholesterol、gluc、smoke、alco 做 `pd.get_dummies`
- 离差标准化：`MinMaxScaler`
- 新增特征：`BMI = weight / (height/100)²`
- 数据集划分：`train_test_split`，测试集占 20%，`random_state=2`

### 4. 模型构建

| 模型 | 实现 | 关键参数 |
| --- | --- | --- |
| 逻辑回归 | `LogisticRegression` | penalty=l2，C=0.6，solver=liblinear，class_weight=balanced |
| 随机森林 | `RandomForestClassifier` | n_estimators=100，random_state=42 |
| 梯度提升树 | `GradientBoostingClassifier` | n_estimators=100，learning_rate=0.1，max_depth=4 |
| KNN | `KNeighborsClassifier` | n_neighbors=10 |
| SVM | `SVC` | gamma=auto |

### 5. 模型评估

| 模型 | F1 | 准确率 |
| --- | --- | --- |
| 逻辑回归 | 0.73 | 72.83% |
| 随机森林 | 0.72 | 71.88% |
| 梯度提升树 | 0.74 | 73.58% |

梯度提升树效果最好，对其做进一步优化。

### 6. 网格搜索调参

使用 `GridSearchCV`（`scoring='roc_auc'`，五折交叉验证），依次搜索 n_estimators、max_features、max_depth 以及三者联合空间，找到最优参数后重新训练。

## 项目结论

项目基于机器学习模型对心血管疾病诊断数据进行了分析和预测，通过数据预处理、探索性分析和分类建模三个阶段进行了深入挖掘。在数据预处理中，根据身高和体重的变化范围、血压的变化范围剔除了部分异常值； 在数据探索性分析中，新增了BMI指标特征，并通过分组对比了不同种类的人群中的患病占比； 在分类建模过程中，分别使用了不同方法进行预测，通过对比预测准确率和F1值对模型进行评估，结果发现GBDT的预测效果最好，准确率 73.58%，F1 为 0.74。从模型的预测结果来看，收缩压ap_hi、年龄age、体重指数BMI、体重weight等特征对心血管疾病的诊断起着重要作用，因而在实际心血管疾病诊断时，可重点参考这些指标。最终，通过有效的预测来降低心血管病的发生率和死亡率，让心血管疾病更及时被发现并尽早对其根治。

## 体会与总结
数据集中的数据多为离散型数据，做可视化时让我无从下手，经过思考想到既然数据的结果只有两三种情况，那么利用现成分好类的数据进行value_count()就易获得饼图、条形图，而直方图寻找一个连续性数据的字段即可。
判断离散型数据与连续型数据的区别时，从毫无头绪到逐渐清晰，我的理解就是离散型数据能够进行分类，而连续型若对其分类是分不完的，可以有无穷多种类型，所以不能够进行分类。
在模型优化过程中，由于数据集较大，等待时间较长，所以我尽可能确保代码的准确性，同时想一想下一步优化应该如何写，在运行结束时，得到的准确率为负数，因为分类模型在Grid SearchCV网格优化模型中的scoring参数需要更改，改为guc_auc即可。
